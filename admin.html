২️⃣ লাইভ প্রকাশ — সব ভিজিটরের জন্য

GitHub → Settings → Developer settings → Personal access tokens → শুধু gist স্কোপ দিয়ে টোকেন বানান। এরপর gist.github.com-এ azadi-config.json নামে একটি public gist তৈরি করে তার ID এখানে দিন। টোকেন শুধু এই ডিভাইসের localStorage-এ থাকে — কনফিগে কখনো প্রকাশ হয় না।
jsonbin.io-তে ফ্রি অ্যাকাউন্ট খুলে একটি public bin বানান — Bin ID ও Master Key এখানে দিন।

📱 মোবাইল অ্যাপ: ডিপ্লয় করা সাইটে /admin.html খুলে ব্রাউজার মেনু থেকে "Add to Home Screen" দিলে এটি আলাদা অ্যাপ হিসেবে ইন্সটল হবে — শুধু আপনার ফোনে।

🔄 প্রকাশ-প্রবাহ: সংবাদ/বিজ্ঞাপন লিখুন → "লোকাল প্রিভিউ" দিয়ে যাচাই → "লাইভ প্রকাশ" চাপুন → কনফিগ Gist/JSONBin-এ আপলোড হয় → প্রতিটি ভিজিটরের ব্রাউজার পেজ লোডের সময় সেই কনফিগ পড়ে নেয়। সাইট রি-ডিপ্লয় লাগে না।

⚙️ প্রথম সেটআপ (একবারই): প্রথম প্রকাশের পর নিচে যে পাবলিক রিড URL পাবেন সেটি site-config.js ফাইলের remoteConfigUrl-এ বসিয়ে একবার ডিপ্লয় করুন।

🛡️ নিরাপত্তা সত্য: পাসকোড-গেট শুধু আড়াল; আসল সুরক্ষা হলো আপনার টোকেন — সেটি ছাড়া কেউ কিছুই বদলাতে পারবে না, কারণ লেখার ক্ষমতা শুধুই টোকেনধারীর। টোকেন এই ডিভাইসেই থাকে, কখনো প্রকাশিত কনফিগে যায় না।
