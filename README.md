# বাংলা নিউজ এডিশন (BNE) — স্ট্যাটিক সংস্করণ (Netlify-রেডি)

**কোনো সার্ভার, ডাটাবেস, বিল্ড বা খরচ নেই।** ভিজিটরের ব্রাউজারই CORS-প্রক্সির মাধ্যমে
৯টি বাংলা সংবাদ সূত্রের RSS ফিড সরাসরি টানে — তাই **প্রতিটি রিফ্রেশেই সর্বশেষ খবর**।

## ডিপ্লয় (৩টি উপায়, সবগুলোই ফ্রি)

### ১. Netlify Drop (সবচেয়ে সহজ — ৩০ সেকেন্ড)
1. https://app.netlify.com/drop খুলুন
2. এই প্রজেক্ট ফোল্ডারটি ড্র্যাগ-অ্যান্ড-ড্রপ করুন (রুটেই সব ফাইল — `static-site/` সাবফোল্ডার নেই)
3. শেষ — লাইভ URL পেয়ে যাবেন

### ২. Netlify + GitHub (অটো-ডিপ্লয়)
- রিপো কানেক্ট করুন → Base/Publish directory: `.` (রুট) → Build command: খালি

### ৩. GitHub Pages / Cloudflare Pages / Vercel Static
- একই ফোল্ডার আপলোড করলেই চলবে — শুধু স্ট্যাটিক ফাইল সার্ভ হয়

## যেভাবে কাজ করে

```
ভিজিটর রিফ্রেশ → ব্রাউজার → CORS প্রক্সি (rss2json → corsproxy → allorigins → codetabs, ক্রমিক fallback)
              → ৯টি RSS ফিড (সমান্তরাল, per-source টাইমআউট ও আইসোলেশন)
              → DOMParser দিয়ে XML/JSON পার্স → কিওয়ার্ড-ভিত্তিক বাংলা ক্যাটাগরাইজেশন
              → localStorage ক্যাশ (৫ মিনিট TTL, stale-while-revalidate)
              → তাৎক্ষণিক রেন্ডার (হিরো + গ্রিড + ১৩ বিভাগ + টিকার + আর্টিকেল ভিউ + সার্চ)
```

- **তাৎক্ষণিক লোড:** আগের ভিজিটের ক্যাশ সাথে সাথে দেখায়, ব্যাকগ্রাউন্ডে নতুন খবর মার্জ হয়
- **অটো-রিফ্রেশ:** ট্যাব খোলা থাকলেও প্রতি ৫ মিনিটে নিজে নিজে হালনাগাদ
- **Graceful degradation:** কোনো সূত্র/প্রক্সি ডাউন থাকলে বাকিগুলো দিয়েই চলে
- **রাউটিং:** hash-ভিত্তিক (`#/`, `#/category/খেলা`, `#/news/<id>`, `#/search/<q>`) — স্ট্যাটিক হোস্টে
  কোনো সার্ভার-রিরাইট কনফিগ ছাড়াই কাজ করে
- **PWA/অফলাইন:** সার্ভিস ওয়ার্কার (`sw.js`) মূল অ্যাসেট ক্যাশ করে — অফলাইনেও সাইট খোলা যায়,
  `manifest.webmanifest`-এর মাধ্যমে মোবাইলে অ্যাপ হিসেবে ইনস্টল করা যায়

## 📱 ফেসবুক পেজ অটো-পোস্টিং (প্রিভিউসহ)

GitHub Actions প্রতি ৩০ মিনিটে নতুন সংবাদ টেলিগ্রাম চ্যানেল **এবং** ফেসবুক পেজে
**প্রিভিউসহ** পোস্ট করে — টেলিগ্রামে ছবি+ক্যাপশন কার্ড, ফেসবুকে OG প্রিভিউ কার্ড
(ডায়নামিক শিরোনাম/ছবি/সারাংশ, `FB_POST_MODE=photo` দিলে বড় ছবি+ক্যাপশন)।
কোনো খবর দ্বিতীয়বার পোস্ট হয় না (`last_posted.json` ডিডুপ)।

**চালু করতে (১৫ মিনিট):**
1. [FB_SETUP_GUIDE.md](FB_SETUP_GUIDE.md) অনুসরণ করে ফেসবুক **Page Access Token** নিন
2. GitHub রিপোতে এই **Secrets** যোগ করুন: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`,
   `FB_PAGE_TOKEN`, `FB_PAGE_ID` (ঐচ্ছিক: `FB_POST_MODE`, `MAX_POSTS_PER_RUN`)
3. শেষ — পরের ৩০ মিনিটের রান থেকেই পেজে অটো-পোস্ট শুরু

## ফাইল গঠন

| ফাইল | কাজ |
|------|-----|
| `index.html` | মূল পোর্টাল পেজ |
| `app.js` | সার্ভারবিহীন লাইভ সংবাদ ইঞ্জিন (ফিড → পার্স → রেন্ডার) |
| `style.css` | সম্পূর্ণ স্টাইল (লাইট/ডার্ক থিম, রেসপনসিভ) |
| `site-config.js` | ডিফল্ট কনফিগ (সম্পাদকীয় সংবাদ + বিজ্ঞাপন + GA4/AdSense) |
| `data/bne-config.json` | রিমোট কনফিগ (GitHub-এ কমিট হলে লাইভ আপডেট) |
| `admin.html` | পাসকোড-সুরক্ষিত কাস্টমাইজেশন সেন্টার (নিউজ/অ্যাড CRUD + প্রকাশ) |
| `sw.js` | মেইন-সাইট সার্ভিস ওয়ার্কার (অফলাইন/PWA) |
| `sw-admin.js` | লিগ্যাসি অ্যাডমিন SW (বর্তমানে ব্যবহৃত নয়) |
| `manifest.webmanifest` | মেইন-সাইট PWA ম্যানিফেস্ট |
| `admin-manifest.json` | অ্যাডমিন PWA ম্যানিফেস্ট |
| `auto_social_poster.js` | GitHub Actions-চালিত টেলিগ্রাম/ফেসবুক অটো-পোস্টার (টোকেন শুধু env থেকে) |
| `sponsor_hunter.js` | স্পনসর লিড জেনারেটর ও Gmail আউটরিচ (বাস্তব ইমেইল বসাতে হবে) |
| `sitemap.xml`, `robots.txt`, `ads.txt` | SEO ও AdSense |
| `about-us.html`, `privacy-policy.html`, `contact-us.html` | স্ট্যাটিক পেজ |

## নিরাপত্তা নোট

- **টোকেন কখনো কোডে থাকে না** — GitHub Actions-এ `TELEGRAM_BOT_TOKEN`, `FB_PAGE_TOKEN`,
  `GMAIL_APP_PASS` ইত্যাদি Secrets হিসেবে দিন।
- `sponsor_hunter.js`-এর `TARGET_AGENCIES`-এর ইমেইলগুলো প্লেসহোল্ডার — লাইভ আউটরিচের আগে বদলান।
- অ্যাডমিন গেট শুধু আড়াল; আসল সুরক্ষা আপনার GitHub Token (শুধু আপনার ডিভাইসে থাকে)।

## সীমাবদ্ধতা (সৎ ঘোষণা)

- আর্টিকেল বডি = ফিডের সারাংশ (প্লেইন-টেক্সট, নিরাপদভাবে রেন্ডার করা) + মূল সূত্রের লিংক।
  ফুল-বডি স্ক্র্যাপিং/AI-রিরাইটের জন্য সার্ভার লাগে।
- ফ্রি পাবলিক CORS-প্রক্সির রেট-লিমিট থাকতে পারে; তাই একাধিক প্রক্সির fallback চেইন +
  localStorage ক্যাশ রাখা হয়েছে।
