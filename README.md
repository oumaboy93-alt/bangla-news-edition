# দৈনিক আজাদী মুভমেন্ট — স্ট্যাটিক সংস্করণ (Netlify-রেডি)

**কোনো সার্ভার, ডাটাবেস, বিল্ড বা খরচ নেই।** ভিজিটরের ব্রাউজারই CORS-প্রক্সির মাধ্যমে
৮টি বাংলা সংবাদ সূত্রের RSS ফিড সরাসরি টানে — তাই **প্রতিটি রিফ্রেশেই সর্বশেষ খবর**।

## ডিপ্লয় (৩টি উপায়, সবগুলোই ফ্রি)

### ১. Netlify Drop (সবচেয়ে সহজ — ৩০ সেকেন্ড)
1. https://app.netlify.com/drop খুলুন
2. এই `static-site` ফোল্ডারটি ড্র্যাগ-অ্যান্ড-ড্রপ করুন
3. শেষ — লাইভ URL পেয়ে যাবেন

### ২. Netlify + GitHub (অটো-ডিপ্লয়)
- রিপো কানেক্ট করুন → Base/Publish directory: `static-site` → Build command: খালি

### ৩. GitHub Pages / Cloudflare Pages / Vercel Static
- একই ফোল্ডার আপলোড করলেই চলবে — শুধু স্ট্যাটিক ফাইল সার্ভ হয়

## যেভাবে কাজ করে

```
ভিজিটর রিফ্রেশ → ব্রাউজার → CORS প্রক্সি (allorigins → corsproxy → codetabs, ক্রমিক fallback)
              → ৮টি RSS ফিড (সমান্তরাল, per-source টাইমআউট ও আইসোলেশন)
              → DOMParser দিয়ে XML পার্স → কিওয়ার্ড-ভিত্তিক বাংলা ক্যাটাগরাইজেশন
              → localStorage ক্যাশ (৫ মিনিট TTL, stale-while-revalidate)
              → তাৎক্ষণিক রেন্ডার (হিরো + গ্রিড + ৮ বিভাগ + টিকার + আর্টিকেল ভিউ)
```

- **তাৎক্ষণিক লোড:** আগের ভিজিটের ক্যাশ সাথে সাথে দেখায়, ব্যাকগ্রাউন্ডে নতুন খবর মার্জ হয়
- **অটো-রিফ্রেশ:** ট্যাব খোলা থাকলেও প্রতি ৫ মিনিটে নিজে নিজে হালনাগাদ
- **Graceful degradation:** কোনো সূত্র/প্রক্সি ডাউন থাকলে বাকিগুলো দিয়েই চলে
- **রাউটিং:** hash-ভিত্তিক (`#/`, `#/category/খেলা`, `#/news/<id>`) — স্ট্যাটিক হোস্টে
  কোনো সার্ভার-রিরাইট কনফিগ ছাড়াই কাজ করে

## সীমাবদ্ধতা (সৎ ঘোষণা)

- আর্টিকেল বডি = ফিডের সারাংশ (প্লেইন-টেক্সট, নিরাপদভাবে রেন্ডার করা) + মূল সূত্রের লিংক।
  ফুল-বডি স্ক্র্যাপিং/AI-রিরাইটের জন্য সার্ভার লাগে — সেটির জন্য মূল ফুলস্ট্যাক
  পোর্টাল (`/` রুট প্রজেক্ট) বা পাইথন এজেন্ট (`agent/`) ব্যবহার করুন।
- ফ্রি পাবলিক CORS-প্রক্সির রেট-লিমিট থাকতে পারে; তাই ৩টি প্রক্সির fallback চেইন +
  localStorage ক্যাশ রাখা হয়েছে।
