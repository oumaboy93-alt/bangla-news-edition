# legacy/ — অবসরপ্রাপ্ত স্ক্রিপ্ট

> **নীতি:** এখানে কেবল ডকুমেন্টেশন থাকে — চলমান কোড নয়।
> Netlify `--dir .` দিয়ে পুরো রেপো রুট প্রকাশ করে, তাই এখানে কোনো `.js`,
> `.html` বা চাবিযুক্ত ফাইল রাখলে সেটি `https://<domain>/legacy/...` পথে
> আবার সর্বজনীন হয়ে যেত। সরানো স্ক্রিপ্টগুলো Git ইতিহাসে অটুট আছে
> (`git log --follow -- <path>`), দরকার হলে সেখান থেকে দেখা যাবে।

## fb_group_bot.js — আর চালাবেন না (ফাইলটি ট্রি থেকে সরানো হয়েছে)
Playwright দিয়ে ব্রাউজার অটোমেশন করে পাবলিক ফেসবুক গ্রুপে পোস্ট করা Meta-র
শর্তভঙ্গ। এতে যে ব্যক্তিগত অ্যাকাউন্ট ব্যাকএন্ডে আছে সেটি সীমাবদ্ধ বা বন্ধ হয়ে
যেতে পারে। এটি স্ক্রিপ্ট থেকে সরানো হয়েছে এবং কোনো ওয়ার্কফ্লোতে শিডিউল করা নেই।

এর বদলে যা ব্যবহার করবেন:
- অফিসিয়াল Graph API দিয়ে নিজের মালিকানাধীন Facebook **পেজে** পোস্ট
  (এখন এটাই `auto_social_poster.js` করে)
- আপনার নিজের Telegram চ্যানেল (একই স্ক্রিপ্ট করে)

গ্রুপে ছড়াতে চাইলে ম্যানুয়ালি শেয়ার করুন — অটোমেশন নয়।
